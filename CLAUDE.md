# Правила проекта

Этот проект — набор простых лендингов/визиток на чистом HTML.

## Структура файлов

- Каждая страница — один самостоятельный HTML-файл (например `landing.html`, `vizitka.html`).
- Никаких внешних библиотек и фреймворков (без React, Bootstrap, Tailwind CDN и т.п.).
- Все стили — внутри `<style>` в самом файле. Весь JS (если нужен) — внутри `<script>` в самом файле.
- Не создавать отдельные `.css`/`.js` файлы — всё должно быть в одном HTML.
- Единственное исключение — скрипт `https://forms.yandex.ru/_static/embed.js` для формы приёма заявок: это не дизайн-библиотека, а обязательная часть уже готовой рабочей формы Яндекс.Форм, без которой форма может работать некорректно.
- Второе исключение — шрифты Montserrat и Inter, подключаемые через `<link>` на fonts.googleapis.com: это шрифты, а не JS/CSS-фреймворк, Google Fonts — надёжный и быстрый CDN.

## Дизайн

- Тёмный фон, светлый текст.
- Акцентный цвет — оранжевый (используется для кнопок, ссылок, заголовков, выделений).
- Адаптивная вёрстка — страница должна хорошо выглядеть и удобно читаться на мобильных устройствах (проверять на узких экранах).

## Текст и стиль

- Пишем просто и дружелюбно, как будто объясняешь человеку лично.
- Без канцелярита, без официоза, без сложных оборотов.
- При формулировке любых текстов на сайте (заголовки, описания, кнопки, тексты в карточках) следовать принципам книги Максима Ильяхова «Пиши, сокращай»: убирать лишние слова и канцеляризмы, писать понятно и по делу, вести читателя к цели (заказу видео), не грузить формулировками.

## Рабочий процесс

- Перед созданием нового файла — сначала рассказать, что планируется сделать, и только потом создавать файл.
